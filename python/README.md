# Python 副线（每天 20–30 分钟）

| 阶段 | 周次 | 内容 |
|---|---|---|
| 1 语法入门 | 12–13 | print/input、类型、字符串、列表/元组/字典/集合、切片、分支循环、函数、lambda |
| 2 工程习惯 | 14–15 | 模块与包、pip、venv、main 入口、文件读写(with)、异常处理 |
| 3 面向对象 | 16–17 | 类、init、str/repr/eq 魔术方法、继承与多态、鸭子类型、abc |
| 4 数据结构 | 18–19 | 用 Python 重写栈/队列/链表/二叉树；collections.deque、迭代器与生成器 |
| 5 算法对照 | 20–22 | 用 Python 重写二分、快排、DP、BFS/DFS；与 C++ 写法差异对比 |
| 6 工具库 | 23–24 | os/sys/pathlib、datetime、re 正则、json/csv、requests、hashlib |
| 7 数据与绘图 | 25–26 | numpy 基础、matplotlib 画图、pandas 读 CSV 统计 |
| 8 安全实战 | 27–29 | 端口探测脚本、批量爆破(授权靶场)、日志分析、hashlib 破解 |
| 9 进阶 | 30–32 | struct 解析二进制(ELF 头解析器)、ctypes 调用 C 库、subprocess 调自己写的 C++ 工具 |
| 10 交付 | 33–35 | 把 C++ 工具用 Python 包一层命令行；写 README；整理脚本合集 |

**每天 30 分钟模板**：15 min 视频/文档（黑马 Python 或廖雪峰）+ 15 min 敲代码（必须写成一个小程序）。
