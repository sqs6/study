            注：前缀和后缀的**优先级是一样的**（都是一元运算符），差别不在优先级，而在**求值顺序**：
                前置 ++a 是「先加后用」，后置 a++ 是「先用后加」。
                但一条表达式里不要对同一个变量连用两次自增——例如 c = a++ + ++a;
                同一个 a 在两个序列点之间被改了两次，这在 C 标准里是**未定义行为**（结果随编译器优化而变）。
                这跟 Windows / macOS / Linux 无关。

            例：
            a=10 b=5
            c=a++ + ++a- --b - a--       //c=11+11-4-11=7

2.switch语句  作用：把所有选择一一列举出来，根据不同的条件任选其一
switch (表达式)       //提变量，后面case里面找对应变量，输出该行
{
case(a, 判断表达式是否和a相等):  //表达式只能是字符或者整数
    printf();
    break;//结束case分支的运行

    case...
    
    default:       //不满足任意一种case
        break;
        printf()

}
switch细节：
①表达式只能是字符或者是整数 ，例如int a；switch（a）//强调int
②case里面的a只能是（字符 / 整数）的字面量，不能是变量；case后面的值不能重复
③break表示结束，结束switch语句。
④default：所有case都不符合情况

* **其他使用细节
* ①default的位置随便放，也可以省略（如果所有从case都不符合，最后直接跳出switch语句）
* ②switch if 的使用场景
  switch：对有限个case进行匹配，case一般在10个
  if：对一个范围进行判断
  不同点：if运行的时候从上往下，switch直接匹配
* ③case穿透
  如果匹配的case下面不写break，一直往下运行直到遇到break
  细节：穿透只会往下，如果把default放上第一个匹配的case 上面就不会运行default
