```c
返回值数据类型 函数名(形参1, 形参2, ...)
{
    函数体（代码块）;
    return 返回值;
}
```

调用：

```c
函数名(实参1, 实参2, ...);   // 形参与实参必须一一对应
```

常用的无返回值写法：

```c
void 函数名()
{
    函数体
}
```

调用时直接在主函数中写 `函数名();` 就可以直接运行。

#### 三、带有形参的函数

```c
void sum(int num1, int num2)
{
    int sum = num1 + num2;
    printf("%d", sum);
}
```

调用：

```c
sum(2, 50);        // 赋值：num1 = 2，num2 = 50
// 输出 -> 52
```

#### 四、带有返回值的函数

**返回值**就是这个函数参与整体代码运算时的值；要想利用该函数计算，就得把返回值设置成函数本身的运算结果。

- 返回值就是让调用者（main 函数）拿到自定义函数运行结果的值。
- 例：用 `void sum(...)` 虽然能打印出结果，但 main 里若想打印 `sum * 10` 就会出错 —— 因为没有返回值，调用者拿不到函数的值，只能看见、没法使用。
- **重点在于 main 函数想要自定义函数干什么，返回值就填对应的结果**：
  - 只显示计算结果 → 直接用 void（无返回值）
  - 要用结果进一步计算 → 返回值直接填该计算结果

基本格式：

```c
返回值类型 函数名(形参1, 形参2)
{
    函数体
    return 返回值;
}
```

调用的两种写法：

```c
int add = sum1(1, 3);       // 用变量接收函数结果，之后可继续参与运算
printf("%d", sum1(1, 3));  // 直接打印，用函数结果填补占位符
```

完整实例：

```c
#include <stdio.h>

int sum1(int a, int b);   // 自定义函数也要在 main 上面声明，或直接写在 main 上面

int main()
{
    int add = sum1(1, 3);  // 有返回值的函数调用，必须有变量来接收最终结果
    printf("%d", add);
    return 0;
}
```

## 三、数组与常用算法（2026-11）

### 1. 数组基础

**定义格式**：`数据类型 数组名[长度];`

- 特点：连续的内存空间，且长度一旦确定**无法改变**
- **数组初始化**：定义时给第一组值赋值，如 `int arr[3] = {1, 2, 3};`
  - 可以不写长度，编译器按初始值的个数自动确定
  - 若写了长度，长度必须 ≥ 初始值个数
- **元素访问**：`arr[下标]`，下标也叫索引，`arr[5]` 表示数组中的第 6 个元素
- **核心特点：索引从 0 开始，连续 +1，不间断**
- 最大下标 = 长度 − 1；访问 `arr[长度]` 就是越界

**不知道长度时的遍历**：

```c
for (int i = 0; i < 长度 - 1; i++)
{
    printf("%d ", arr[i]);
}
```

**计算数组长度**：

```c
int len = sizeof(arr) / sizeof(int);   // 总字节数 / 单个元素字节数
```

### 2. 数组在内存中的地址

- 内存里的变量都有编号，每个字节编一个号，这个号就叫**内存地址**，地址不会重复
- `int` 占 4 个字节 → 占 4 个内存地址
- 变量取首地址用 `&`：`printf("%p", &a);`（`%p` 是打印指针/内存地址的格式说明符，pointer）
- `arr` 和 `arr[0]` 的值一样，都是第一个元素的首地址；`arr[1]` 是第二个元素第一个字节的地址
- **通过首地址不能确定存储的数据，只能获取第一个字节的数据**
- **索引就是偏移量**

### 3. 数组作为函数参数

- 实际传递的是数组的**首地址**，函数内部拿不到长度
- 在函数里 `arr` 只是一个指针，`sizeof(arr)` 得到的是指针大小（x64 下是 8），**不是数组总长度**
- 所以必须把长度作为**第二个参数**一起传进去

```c
int arr[] = {1, 2, 3, 4, 5};
int len = sizeof(arr) / sizeof(int);   // 记录长度，以便传参后使用
for (int a = 0; a < len; a++)
{
    printf("%d
", arr[a]);
}
```

**越界提醒**：合法下标范围是 `0 <= 下标 <= 长度 - 1`。

### 4. 查找算法

#### ① 顺序查找（从头扫到尾）

思路：从第一个元素开始逐个比较，找到就返回对应下标，找完都没有就返回 −1。

```c
#include<stdio.h>

int search(int arr[], int len, int num);

int main()
{
    int arr[] = {12, 58, 96, 47, 5, 6};
    int num;
    scanf("%d", &num);

    int len = sizeof(arr) / sizeof(int);
    int a = search(arr, len, num);
    printf("%d", a);       // 找到就打印下标，没找到就打印 -1
    return 0;
}

int search(int arr[], int len, int num)
{
    for (int i = 0; i < len; i++)
    {
        if (arr[i] == num)
        {
            return i;
        }
    }
    return -1;
}
```

#### ② 二分查找（折半查找）

- 前提：数组中的数据**必须是有序的**
- 核心逻辑：每次排除一半的查找范围
- 三个游标 `min / mid / max`，`mid = (max + min) / 2`
- 比较 `arr[mid]` 与目标值，确定目标在哪一半，循环缩小范围直到找到

#### ③ 插值查找（二分查找的改进）

- 与二分查找基本相同，只是 mid 的取法变成按比例估算：
  `mid = min + (num - arr[min]) / (arr[max] - arr[min]) * (max - min)`
- 要求数据分布尽量均匀；分布均匀时比二分快，否则反而更慢

#### ④ 分块查找（索引顺序查找）

- 分块原则：
  1. 前一组的最大值小于后一组的全部元素（组间有序，组内可无序）
  2. 分块数量一般取元素个数开方（如 16 个元素分成 4 块）
- 思路：先确定要查找的元素在哪一组，再在组内按顺序查找

### 5. 排序算法

#### ① 冒泡排序

相邻两个比较，小的放前面、大的放后面。

```c
for (int i = 0; i < n - 1; i++)          // 循环 n-1 次，最后一个数不用再比
{
    for (int j = 0; j < n - 1 - i; j++)  // 每轮把最大的送到最后
    {
        if (arr[j] > arr[j + 1])
        {
            int tmp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = tmp;
        }
    }
}
```

#### ② 选择排序

每轮从剩下的数里挑最小的放到前面。

```c
for (int i = 0; i < n - 1; i++)
{
    for (int j = i + 1; j < n; j++)
    {
        if (arr[i] > arr[j])
        {
            int tmp = arr[i];
            arr[i] = arr[j];
            arr[j] = tmp;
        }
    }
}
```

### 6. 指针补充：二级指针与二维数组

**二级指针**：指向指针变量的指针。

```c
int** p;        // 第一个 * 表示指向一级指针，第二个 * 是定义指针的标记
int* p = &a;
int** pp = &p;
// pp = &b 之后，*p 就变成了 b
```

- 作用：二级指针可以改变一级指针记录的地址；`printf("%d", **pp)` 可以打印出一级指针指向的值

**数组指针的退化规则**：

```c
int* p = arr;   // arr 参与运算时退化为第一个元素的指针，步长 4（int）
for (int i = 0; i < n; i++) printf("%d", *p++);
```

**不退化**的两种情况：

1. `sizeof` 运算时，`arr` 还是整体
2. `&arr` 取地址时，步长是数组整体大小（数据类型 × 元素个数）

```c
int* p = &arr;   // p 仍是首地址，但 *(p+1) 已经越过整个数组
```

**二维数组的两组定义方式**：

```c
// 方式一：直接定义（元素个数必须都相同）
int arr[m][n] = {
    {1, 2, 3},
    {4, 5, 6},
};

// 遍历要用两层循环，arr[0] 表示第一个一维数组
for (int i = 0; i < m; i++)
{
    for (int j = 0; j < n; j++)
    {
        printf("%d ", arr[i][j]);
    }
    printf("
");
}
```

```c
// 方式二：先定义各一维数组，再用指针数组组成（可长度不同）
int arr1[3] = {...};
int arr2[5] = {...};
int arr3[9] = {...};

int* arr[3] = {arr1, arr2, arr3};   // 装的是三个一维数组的地址
```

### printf / 整除 的两个坑

1. **printf 里要打印 `%` 得写成 `%%` 转义**

```c
printf("%d%%%d", a, b);   // 输出 a%b
```

2. **两个整数相除默认是整除**：`5/9` 的结果是 `0`，想拿到准确结果必须让至少有一个是小数

```c
5 / 9      // 0（整数除法）
5.0 / 9.0  // 0.555556
```

其他需要转义的字符：`\` `/` `;`。

### 8. 原笔记里几处要留意的地方（易错点补充）

**① 指针交换函数里不要丢掉 ***

原笔记这一版有问题：

`c
int swap(int* p1, int* p2)
{
    int temp = *p1;
    p1 = *p2;      // ✘ 这里改的是指针本身，不是它指向的值
    p2 = temp;     // ✘ temp 是 int，赋给 int* 也会报类型错误
}
`

正确写法：

`c
void swap(int* p1, int* p2)
{
    int temp = *p1;
    *p1 = *p2;     // ✔ 对指针所指的空间赋值
    *p2 = temp;    // ✔
}
`

口诀：**形参是指针时，改「指针指向的内容」要带 *，改「指针本身的指向」不带 ***。

**② &arr 的类型不是 int***

`c
int arr[5];
int* p = &arr;          // ✘ 类型不匹配，MSVC 会报错
int (*p)[5] = &arr;     // ✔ 数组指针的正确写法，步长是整个数组
`

原笔记里写 int* p = &arr; 然后用 *(p+1)，这个推导在逻辑上对（步长变成整个数组），
但**类型上不合法**，编译器会报 warning/error。考试和 OJ 里要写对类型。

**③ oid* 做通用交换要按字节处理**

但要注意：**oid* 不能直接解引用**，必须先转成 char* 再逐字节操作，否则编译器报错。
